# Knowledge Base

Curated explanations and reference material derived from the experiments in
this repository.

## Structure

- `00-foundations`: Linux, CUDA, NCCL, and RDMA fundamentals
- `01-distributed-inference`: tensor, pipeline, context, and expert parallelism
- `02-distributed-training`: DDP, FSDP, ZeRO, and optimizer sharding
- `03-large-model-systems`: model serving and large-scale architecture
- `04-ai-cluster`: multi-service cluster design and scheduling
- `05-research`: open questions, hypotheses, and research directions
- `06-transformers`: transformer architecture and implementation details

Experiment-specific observations belong under `experiments/`. Material here
should be consolidated, reviewed, and reusable.
